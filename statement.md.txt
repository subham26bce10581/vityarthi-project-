Problem Statement: Tiered Classification System

The objective of this project is to implement a simple computational model in Python that simulates a tiered classification system for determining medical risk. The program must evaluate inputs from three distinct binary tests and classify the outcome into one of three defined risk levels based on the cumulative count of positive results.

The solution is specifically engineered to demonstrate the mastery of the core concepts mandated by the CSEsyllabus.

Project Scope and Required Components

The program is structured around a mandatory Input -> Process -> Report workflow, implemented using three distinct functions.
